# WALLWAVE — Your Space. Your Frequency.

> High-octane Indian streetwear wall tapestries & music collectibles.

## Features
- **Design System:** Minimalist Swiss streetwear aesthetic inspired by Bluorng.
- **Typography:** Authentic **Neue Haas Grotesk** Display & Text (served locally with zero external latency).
- **Dual Mode:** Automatic system theme adaptation (Light / Dark mode) with manual toggle in navbar.
- **Animations:** High-energy continuous right-to-left warning marquee ticker + Bluorng 75ms staggered scroll-trigger animations.
- **Product Experience:** Karan Aujla "Four You" Limited Drop with interactive size selectors, stock counter, and real product lifestyle gallery.
- **Direct Checkout:** Instant WhatsApp ordering redirected to `+91 8699168853` and email customer support.

## Running Locally
Run with any standard local HTTP server:

```bash
# Python 3
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.
